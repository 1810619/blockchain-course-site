# 区块链技术与应用课程网站（案例库整合版）

本目录 `website_public` 可直接作为 GitHub Pages 仓库内容上传。

本版在原网站基础上新增：
- 顶部一级导航“案例库”
- `cases.html`：三级案例库首页
- `case.html?id=案例编号`：统一案例详情页
- 基础认知6个、专题业务8个、综合应用4个，共18个案例
- 每个案例支持在线阅读、案例图示、学生任务、PDF/Word/任务单/报告模板下载、官方参考资料跳转
- 首页新增“学知识—用知识—做实践”资源入口
- 课程资料页新增章节关联案例
- 课程支持页将原“真实案例”调整为“外部案例与拓展阅读”，并加入课程案例库入口

注意：教师指导书、参考答案、教学PPT和事实核验表没有放进公开网站目录。完整教师材料位于总下载包的 `teacher_resources_private`，不要上传到公开 GitHub 仓库。
